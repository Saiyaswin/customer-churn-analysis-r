# Customer Churn Prediction and Analysis Using R

## Project Overview

This project focuses on analyzing customer churn using data science techniques in R.

The main goal is to understand the factors associated with customer churn and develop
classification models that can help identify customers who may be at higher risk of leaving.

## Project Objectives

- Understand customer churn patterns
- Clean and preprocess customer data
- Perform exploratory data analysis
- Identify important churn-related variables
- Develop classification models
- Compare model performance
- Interpret the results and communicate useful insights

## Technologies Used

- R
- RStudio
- tidyverse
- dplyr
- ggplot2
- tidymodels
- Logistic Regression
- Decision Tree
- Random Forest

## Project Methodology

The project will follow these stages:

1. Problem Definition
2. Background Research
3. Data Collection
4. Data Cleaning
5. Exploratory Data Analysis
6. Feature Engineering
7. Model Development
8. Model Evaluation
9. Result Interpretation
10. Final Reporting

## Planned Models

### Logistic Regression

Used as an interpretable baseline classification model.

### Decision Tree

Used to understand customer churn through simple decision rules.

### Random Forest

Used to capture more complex relationships in the customer data.

## Model Evaluation

The models will be evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix
